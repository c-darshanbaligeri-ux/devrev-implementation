## Get started

If you're new to DevRev, review the core concepts documentation before diving in. After creating a DevRev account, you can access the APIs using a personal access token (PAT), which is generated within the DevRev application. A short tutorial walks you through accessing the APIs.

## Methods

The supported APIs follow the OpenAPI Specification 3.0. You can download these specifications and use any OpenAPI 3.0-compliant tooling to render them, generate SDKs, or perform other actions. There are two versions of the DevRev API available:

- **Public**
- **Beta** (early access)

Use the drop-down menu in the upper-left corner of the site to switch between versions.

Webhooks are also supported so you can react to events from the DevRev platform.

## Snap-ins

A variety of snap-ins can be found on the DevRev Marketplace. Additionally, the snap-in framework lets you build your own snap-ins to automate DevRev workflows or integrate with external systems.
