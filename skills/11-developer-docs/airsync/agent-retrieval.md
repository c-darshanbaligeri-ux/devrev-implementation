## Agent retrieval

The site exposes each page as Markdown: append `/llms.txt` to its documentation URL, for example `/airsync/runtime/llms.txt`. The [site index](https://developer.devrev.ai/llms.txt) lists retrievable pages. Read the runtime contract together with a capability page before generating code; follow its verification conditions after implementation.

Start with [connector capabilities](getting-started.md#capability-dependencies), then retrieve the contracts for the capability you are implementing.
