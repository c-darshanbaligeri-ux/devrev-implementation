## `POST /chats.create`

**Create Chat**

Source: <https://developer.devrev.ai/api-reference/chats/create>

Creates a new chat, or optionally opens an existing one.

**Required scopes:** Access is determined by chat membership.

### Request Body (`application/json`)

The site presents this body as alternative variant schemas (tabs); each table below is one variant.

#### Variant `chats-create-request-dm`

| Field | Required | Type | Description |
| --- | --- | --- | --- |
| `type` | no | `string` | *Value in: "dm"* |
| `custom_fields` | no | `object` | Application-defined custom fields. |
| `custom_schema_spec` | no | `custom-schema-spec` | Custom schemas described using identifiers. Each custom field in the request must have the corresponding schema specified; omission results in a Bad Request error. If a custom schema is not included in the specifier, it remains unchanged. For surfaces with human interactors, it is recommended to provide tenant_fragment: true and validate_required_fields: true. |
| `get_if_conflict` | no | `boolean` | If true and a chat already exists with unique properties that conflict with the chat creation, then the existing chat is returned without error, otherwise if false, a conflict error is returned. |
| `title` | no | `string` | The title for the chat.<br>*Format: text* |
| `is_default` | no | `boolean` | Whether this is the default DM for messaging the constituent users. If true, then this DM is always returned when opening a DM for the users. Note only one DM may be the default for a given set of users. By Default, this is true. |
| `records` | no | `array<string>` | The associated records for this DM.<br>*Items: items <= 16* |
| `shared_with` | no | `array<set-shared-with-membership>` | The list of members with whom the DM is shared. |
| `users` | yes | `array<string>` | The users or groups to send direct messages to. The authenticated user must be included in this list.<br>*Items: 1 <= items <= 16* |

### Response codes

- `201` — `application/json`
- `400` — `application/json`
- `401` — `application/json`
- `403` — `application/json`
- `413` — `application/json`
- `429` — `application/json`
- `500` — `application/json`
- `503` — `application/json`

### cURL example

```bash
curl -X POST "https://api.devrev.ai/chats.create" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "dm",
    "users": [
      "DEVU-12345"
    ]
  }'
```
