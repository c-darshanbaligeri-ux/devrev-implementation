## `GET /sys-users.list`

**List Sys Users**

Source: <https://developer.devrev.ai/api-reference/sys-users/list>

Lists system users within your organization.

**Required scopes:** Default Scopes unavailable for this API.

### Query Parameters

| Field | Required | Type | Description |
| --- | --- | --- | --- |
| `cursor` | no | `string` | The cursor to resume iteration from. If not provided, then iteration starts from the beginning.<br>*Format: text* |
| `limit` | no | `integer` | The maximum number of system users to return. Value can range from '1' to '100', with a default of '50'.<br>*Format: int32* |
| `mode` | no | `string` | The iteration mode to use, otherwise if not set, then "after" is used.<br>*Value in: "after" \| "before"* |
| `sort_by` | no | `array<string>` | Fields to sort the system users by and the direction to sort them. |

### Response codes

- `200` — `application/json`
- `400` — `application/json`
- `401` — `application/json`
- `403` — `application/json`
- `413` — `application/json`
- `429` — `application/json`
- `500` — `application/json`
- `503` — `application/json`

### cURL example


## `POST /sys-users.list`

**List Sys Users (POST)**

Source: <https://developer.devrev.ai/api-reference/sys-users/list-post>

Lists system users within your organization.

**Required scopes:** Default Scopes unavailable for this API.

### Request Body (`application/json`)

| Field | Required | Type | Description |
| --- | --- | --- | --- |
| `cursor` | no | `string` | The cursor to resume iteration from. If not provided, then iteration starts from the beginning.<br>*Format: text* |
| `limit` | no | `integer` | The maximum number of system users to return. Value can range from '1' to '100', with a default of '50'.<br>*Format: int32* |
| `mode` | no | `string` | The iteration mode to use. If "after", then entries after the provided cursor will be returned, or if no cursor is provided, then from the beginning. If "before", then entries before the provided cursor will be returned, or if no cursor is provided, then from the end. Entries will always be returned in the specified sort-by order.<br>*Value in: "after" \| "before"* |
| `sort_by` | no | `array<string>` | Fields to sort the system users by and the direction to sort them. |

### Response codes

- `200` — `application/json`
- `400` — `application/json`
- `401` — `application/json`
- `403` — `application/json`
- `413` — `application/json`
- `429` — `application/json`
- `500` — `application/json`
- `503` — `application/json`

### cURL example

```bash
curl -X POST "https://api.devrev.ai/sys-users.list" \
  -H "Content-Type: application/json" \
  -d '{}'
```

## `POST /sys-users.update`

**Update Sys User**

Source: <https://developer.devrev.ai/api-reference/sys-users/update>

Updates the system user.

**Required scopes:** Default Scopes unavailable for this API.

### Request Body (`application/json`)

| Field | Required | Type | Description |
| --- | --- | --- | --- |
| `display_name` | no | `string` | Updated display name for the system user.<br>*Format: text* |
| `display_picture` | no | `string\|null` | Artifact ID of the system user's new display picture.<br>*Format: id* |
| `full_name` | no | `string` | Updated full name for the system user.<br>*Format: text* |
| `id` | yes | `string` | The ID of system user to update.<br>*Format: id* |

### Response codes

- `200` — `application/json`
- `400` — `application/json`
- `401` — `application/json`
- `403` — `application/json`
- `404` — `application/json`
- `413` — `application/json`
- `429` — `application/json`
- `500` — `application/json`
- `503` — `application/json`

### cURL example

```bash
curl -X POST "https://api.devrev.ai/sys-users.update" \
  -H "Content-Type: application/json" \
  -d '{
    "id": "string"
  }'
```
