`works` endpoint

ℹ️ A work item is a record of some work that has to be done for a customer (ticket) or for another builder or maintainer of a part (issue).

📌 For more information about work items, refer to [Tickets](https://support.devrev.ai/devrev/article/ART-21861) and [Issues](https://support.devrev.ai/devrev/article/ART-21870).
