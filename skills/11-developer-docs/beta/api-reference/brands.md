## `POST /brands.create`

**Create Brand**

Source: <https://developer.devrev.ai/beta/api-reference/brands/create>

Creates a new brand.

### Request Body (`application/json`)

| Field | Required | Type | Description |
| --- | --- | --- | --- |
| `description` | no | `string` | Description of the brand to be created.<br>*Format: text*<br>*Length: length <= 65536* |
| `name` | yes | `string` | Name of the brand to be created.<br>*Format: text*<br>*Length: 1 <= length <= 50* |

### Response codes

- `201` — `application/json`
- `400` — `application/json`
- `401` — `application/json`
- `403` — `application/json`
- `409` — `application/json`
- `413` — `application/json`
- `429` — `application/json`
- `500` — `application/json`
- `503` — `application/json`

### cURL example

```bash
curl -X POST "https://api.devrev.ai/brands.create" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "string"
  }'
```
