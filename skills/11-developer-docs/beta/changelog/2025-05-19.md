# May 19, 2025

Source: <https://developer.devrev.ai/beta/changelog/2025-05-19>
Scraped: 2026-11-03

## New Endpoints

### Artifacts

* [`/artifacts.versions.delete`](../api-reference/artifacts.md#hard-delete-version): Delete an artifact version

### Brands

* [`/brands.create`](../api-reference/brands.md#create): Create a new brand
* [`/brands.delete`](../api-reference/brands.md#delete): Delete an existing brand
* [`/brands.get`](../api-reference/brands.md#get-post): Get the information for a brand
* [`/brands.list`](../api-reference/brands.md#list-post): List brands matching a given filter
* [`/brands.update`](../api-reference/brands.md#update): Update an existing brand

### Links

* [`/links.replace`](../api-reference/links.md#replace): Replace a link

### Metrics

* [`/metric-trackers.get`](../api-reference/slas.md#metric-trackers-get-post): Get a metric tracker

## Modified Endpoints

### Accounts

* Added `subtype` and `tier` query parameters to [`/accounts.export`](../api-reference/accounts.md#export-post) and [`/accounts.list`](../api-reference/accounts.md#list-post)
* Added `drop` property to `custom_schema_spec` in [`/accounts.create`](../api-reference/accounts.md#create) and [`/accounts.update`](../api-reference/accounts.md#update)

### Articles

* Added `content_format` and `data_sources` properties in [`/articles.create`](../api-reference/articles.md#create-article) and [`/articles.update`](../api-reference/articles.md#update-article)
* Made `applies_to_parts` optional in [`/articles.create`](../api-reference/articles.md#create-article)

### Commands

* Added `ai_assistant_chat` and `dm` to allowed object types in surface configuration for [`/commands.create`](../api-reference/commands.md#create), [`/commands.update`](../api-reference/commands.md#update) and related endpoints

### Conversations

* Added `state` query parameter to [`/conversations.list`](../api-reference/conversations.md#list-post) and [`/conversations.export`](../api-reference/conversations.md#export-post)
* Modified `owned_by.set` to allow empty arrays in [`/conversations.update`](../api-reference/conversations.md#update)

### Groups

* Added filtering by `created_by`, `name`, and `sync_metadata` fields to [`/groups.list`](../api-reference/groups.md#list-post)

### Links

* Added `custom_link_type` property to link objects in [`/links.create`](../api-reference/links.md#create) and related endpoints

### Meetings

* Added `sync_metadata` property to meeting objects in [`/meetings.create`](../api-reference/meetings.md#create) and related endpoints

### Opportunities

* Added `contacts` property to opportunity objects in work-related endpoints

### SLAs

* Added `subtype` and `tier` properties to account selector in [`/slas.create`](../api-reference/slas.md#create) and [`/slas.update`](../api-reference/slas.md#update)

### Webhooks

* Added `sla_tracker_fetched` event type to [`/webhooks.create`](../api-reference/webhooks.md#create), [`/webhooks.update`](../api-reference/webhooks.md#update) and related endpoints

### Widgets

* Added `combination` visualization type
* Removed `percentage_precision` from PVP metric configuration

## Schema Changes

### Custom Schema Spec

Added `drop` property to `custom_schema_spec` in multiple endpoints including:

* Account endpoints
* Article endpoints
* Chat endpoints
* Code change endpoints
* Conversation endpoints
* Custom object endpoints
* Dev user endpoints
* Incident endpoints
* Meeting endpoints
* Part endpoints
* Work endpoints

### Meeting Summary

Added new subschema to meeting summary objects affecting multiple endpoints that reference meetings

### Link Summary

Modified link summary schema to support custom link types across multiple endpoints
