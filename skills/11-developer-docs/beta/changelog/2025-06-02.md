# June 2, 2025

Source: <https://developer.devrev.ai/beta/changelog/2025-06-02>
Scraped: 2026-11-03

## New Endpoints

### Chats

* [`/chats.update`](../api-reference/chats.md#update): Updates a chat (DM)

### Record Templates

* [`/record-templates.get`](../api-reference/record-templates.md#record-template-get-post): Gets a record template's information

### Service Accounts

* [`/service-accounts.update`](../api-reference/service-accounts.md#update): Updates a service account's information

### Subscribers

* [`/subscribers.list`](../api-reference/subscribers.md#list-post): Lists subscribers for an object

### Surveys

* [`/surveys.get`](../api-reference/surveys.md#get-post): Gets the information for a survey

## Modified Endpoints

### Accounts

* Adds `primary_account` field, which is set when the account is merged with another

### AI Agents

* Adds `suggestions` agent response type to the `ai_agent_response` webhook event

### Rev Orgs

* Adds `primary_rev_org` field, which is set when the Rev org (workspace) is merged with another

### Users

* Adds `primary_identity` field, which is set when the user is merged with another
