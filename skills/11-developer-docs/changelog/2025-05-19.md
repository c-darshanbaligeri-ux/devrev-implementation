## Modified Endpoints

### Accounts

Added `tier` filter support to:

* [`/accounts.export`](../api-reference/accounts.md#export-post)
* [`/accounts.list`](../api-reference/accounts.md#list-post)

### Articles

Modified schema for:

* [`/articles.create`](../api-reference/articles.md#create-article)
  * Made `applies_to_parts` optional (removed min items constraint)
  * Added `content_format` and `data_sources` properties
* [`/articles.update`](../api-reference/articles.md#update-article)
  * Added `content_format` and `data_sources` properties

### Conversations

* [`/conversations.list`](../api-reference/conversations.md#list-post) - Added `state` and `actual_close_date` filters
* [`/conversations.update`](../api-reference/conversations.md#update) - Made empty owner sets allowed (removed min items constraint)

### Groups

Added new filters to [`/groups.list`](../api-reference/groups.md#list-post):

* `created_by`
* `name`
* `sync_metadata` related filters

### SLAs

Added `tier` support to account selector in:

* [`/slas.create`](../api-reference/slas.md#create)
* [`/slas.update`](../api-reference/slas.md#update)

### Webhooks

Added new event type `sla_tracker_fetched` across webhook endpoints:

* [`/webhooks.create`](../api-reference/webhooks.md#create)
* [`/webhooks.event`](../api-reference/webhooks.md#event)
* [`/webhooks.get`](../api-reference/webhooks.md#get-post)
* [`/webhooks.list`](../api-reference/webhooks.md#list-post)
* [`/webhooks.update`](../api-reference/webhooks.md#update)

### Works

Added sync history filters to:

* [`/works.export`](../api-reference/works.md#export-post)
* [`/works.list`](../api-reference/works.md#list-post)
