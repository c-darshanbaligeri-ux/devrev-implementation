# Sync Knowledge Base

Sync all AI Agent Guide articles from the DevRev knowledge base to local files.

Run the sync script, then confirm what was downloaded.

This command does not configure agent retrieval. After sync, article content supports guides on **FetchObjectContext**, **HybridSearch**, and NL2SQL — see `../references/toolkit-guide.md` and `agent-create.md` when designing agents.
