07 (Testing) → 09 (Full Examples) → 08 (Quick Reference)Key Principles

Deterministic first — If it can be a workflow, make it a workflow. Use AI only where it adds value. For multi-step work that still needs reasoning, prefer an NL skill over free-form agent improvisation — it plans first, then executes proven steps.

FetchObjectContext > Search — If you have an object ID, fetch it directly. Search is for discovery.

Minimal knowledge sources — Fewer sources = less noise = better results. Add sources only when testing reveals a gap.

Task Success before Accuracy — Fix whether the customer's problem is solved before fixing whether the information is correct.

Delegate multi-step reasoning to an NL skill — when a task needs planning or dynamic, multi-step reasoning beyond a single tool call, use an NL skill (a sub-agent that plans and executes), rather than overloading the parent agent or hand-wiring two agents together.

Test before publish — Always run bulk tests before promoting a draft to live.

Start simple — Begin with the Tool Use pattern. Add complexity (ReAct, Multi-Agent) only when the simple pattern demonstrably fails.Object:
